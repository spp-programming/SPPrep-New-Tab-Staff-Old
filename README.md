# SPP New Tab (staff)
SPP New Tab replaces Chrome's New Tab page when installed. It provides shortcuts to useful websites for ~~students~~ staff.

# What?
There was already a staff version of the extension, @EggbertFluffle didn't publish the modified source code for it. This version is based off of the current student version, with more features.

The link to the staff version is here: https://chromewebstore.google.com/detail/spp-new-tab-staff-2022/cjhnijkabhdhhabdfcmkhbmokmjkbmjj (you MUST be signed into your school Google account)
